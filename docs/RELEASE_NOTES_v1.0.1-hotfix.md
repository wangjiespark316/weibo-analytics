## 修复问题

### 问题描述
AI日报页面存在数据真实性问题。后端接口 `/api/daily-report` 已返回真实日报数据，但前端页面未使用 API 返回内容，仍然存在硬编码假数据：
- 硬编码日期：2026年9月13日
- 硬编码微博数量：1,286条
- 硬编码热点数量：23个
- 硬编码情感比例：正面75.2%
- 硬编码热点内容：豆包AI办公新功能发布等5条假热点
- 硬编码分析洞察：全部为虚构文本

### 影响范围
- AI日报页面（`#daily-report`）
- 首页日报卡片日期显示

### 修复方案

#### 1. 前端AI日报页面重构
- 删除所有硬编码假数据
- 新增 Markdown 渲染函数（支持标题、表格、列表、引用、粗体）
- 动态渲染后端 API 返回的真实日报内容
- 新增加载状态和错误处理
- 新增 AI 生成说明区域（含生成时间、数据范围）

#### 2. 首页日报卡片日期动态化
- 删除硬编码日期 `2026年9月13日`
- 改为根据当前日期动态计算前一天日期
- 使用 `toLocaleDateString` 本地化显示

#### 3. 后端日报生成增强
- 日报标题动态标注日期：`微博数据分析日报（YYYY年MM月DD日）`
- 新增数据统计范围说明：`数据统计范围：YYYY年MM月DD日 00:00 - 24:00`
- 数据概览按前一天日期过滤
