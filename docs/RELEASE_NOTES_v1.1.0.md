# 微博智能分析平台 v1.1.0 — AI 行业情报与销售智能

> 从「关键词微博监控」升级为「AI 行业情报系统 + AI 销售情报助手」。
> 在线演示：https://weibo.vertexlab.tech/ ｜ 仓库：https://github.com/wangjiespark316/weibo-analytics

v1.0 解决了微博数据采集、情感分析、关键词趋势与 AI 日报；**v1.1.0 让系统不再只盯着固定关键词，而是每天自动回答三件事：AI 行业发生了什么、哪些产品/技术正在变化、这些变化对销售意味着什么。**

---

## ✨ 新增能力

### 1. AI 行业情报三层模型
- **AI 热点事件自动发现**：LLM 对当日 AI 相关微博聚类，抽取事件标题、摘要、涉及公司与技术；输出热度评分 `heat_score`、**可信度评分 `event_confidence`**、行业影响与**企业应用机会**；事件分类固定为 8 类枚举（模型发布 / 产品发布 / 公司动态 / 融资投资 / 政策监管 / 技术突破 / 企业应用案例 / 行业趋势），综合排序 `event_rank_score = 0.6×热度 + 0.4×可信度`。
- **AI 产品声量雷达**：内置国内外 AI 产品库（豆包 / DeepSeek / 通义千问 / Kimi / 文心一言 / 腾讯元宝 / 智谱清言、ChatGPT / Claude / Gemini / Copilot / Perplexity），统计提及量、互动热度、增长率与情绪，并自动把增长**归因到具体事件**。
- **AI 技术趋势雷达**：近 7 天 vs 近 30 天对比，识别 Agent、多模态、AI 编程、AI 视频、具身智能、RAG、端侧 AI 等方向的 `rising / stable / declining`，并给出企业落地机会。

### 2. 每日自动化流水线（生产化运行）
- 统一编排：采集 → 事件分析 → 产品分析 → 趋势分析 → AI 行业日报 → **销售机会分析**。
- **运行锁**（`pipeline_lock`）防多实例/重启重复执行；重要步骤**分步自动重试**；`pipeline_logs` 记录每步开始/结束/耗时/错误与重试次数。
- **健康检查**与**日报质量评分**（真实性 / 完整性 / 价值）；通知服务预留飞书 Webhook，未配置时自动降级，不影响主流程。
- 分析口径为**「北京时间前一天全天」完整数据**，每日 08:30 补采后统一分析，避免清晨样本不足导致 0 产出。

### 3. AI 销售情报助手（Sales Copilot）
- 行业销售机会识别（AI 趋势 → 行业 → 场景 → 推荐产品 → 优先级）、客户匹配与 AI 销售话术生成。
- 客户 AI 画像、跟进记录 AI 总结、AI 机会评分、**成交概率预测与推进策略**、销售漏斗（各阶段客户数 / 金额 / 转化率）、今日重点客户任务、销售复盘（日 / 周 / 月）。

### 4. 飞书 CRM 真实接入
- 已接入飞书多维表「客户关系管理系统」**客户、跟进记录、商机三张表**，通过 systemd timer **每日 07:45 自动同步**入库（全量/增量、同步日志、失败可查）。
- 同步后自动重算 AI 评分、成交预测、销售漏斗、销售分析与今日任务，形成「飞书 CRM → AI 分析 → 销售建议 → 驾驶舱」真实数据闭环。

### 5. AI 行业驾驶舱前端
- 由 13 个页面扩展到 **7 大功能区、26 个页面**：新增 AI 事件中心、产品雷达、技术趋势、日报中心、销售机会、销售驾驶舱、客户中心、商机管理、今日任务、成交预测、销售漏斗、销售复盘等。
- 飞书 / Linear 风格，Teal 主题，统一 **IconPark 线性图标**；统一 loading、空状态（无数据即「能力说明 + 企业版规划」，不伪造）与错误重试；支持移动端响应式。

## 🔒 安全与数据真实性
- **0 硬编码业务数据、0 `Math.random()`、0 假统计**；所有页面只展示真实 API / 数据库数据，或由真实数据派生。
- API Key 不落前端：前端经 Nginx `/app-api/` 网关注入 Key，外部 `/api/` 业务接口无 Key 一律 **401**，fail-closed。
- 后端密钥全部走环境变量（`.env`），开源仓库无任何硬编码凭证。
- 历史娱乐数据采用**归档隔离**（`archived_general`，可恢复），不物理删除真实数据，也不混入 AI 行业分析。

## ⚡ 性能与工程
- TiDB **连接池（PooledDB）**+ 线程池并行聚合 + 结果缓存，慢接口冷启动从约 11s 降至约 1.6s，缓存命中毫秒级。
- 热门微博列表修复 N+1 查询；采集收紧为「实时搜索 + 时间窗 + AI 相关性过滤」，聚焦 AI 行业。
- 前端修复快速切页异步竞态、事件/产品数据新鲜度回退、移动端宽表横向滚动、通知「全部已读」刷新后状态丢失、SPA 刷新路由保持、动态页面标题。

## 🐛 关键修复
- 热门微博列表返回全量真实总数 `total_count`，首页「热门微博数」不再固定显示当页条数。
- 销售机会分析纳入**每日流水线自动执行**（原先仅手动），接口无参时默认返回**最新分析日**数据。
- 客户「最近跟进时间」唯一以飞书跟进记录为准（LEFT JOIN 回填，无跟进显式置空），消除 CRM 主表脏值。
- AI 日报页面删除全部硬编码，动态渲染后端真实 Markdown；日报 TOP 热点限定统计日当天并对互动量封顶做归一化。

- 前端：**26 个页面**、22 个侧边导航项；后端：**16 个 API 路由模块**、21 张数据表。

> 演示库中的客户与跟进数据来自飞书多维表样例 CRM，部分跟进记录日期较早属数据集本身状态，系统如实展示，不做任何虚构补全。
