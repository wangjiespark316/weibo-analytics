# 微博智能分析平台 v1.0.0 Final Release Notes

**状态**: 正式发布冻结

## 最终修复说明

本次 v1.0.0-final 版本修复了最终体验巡检中发现的 3 个问题：

### 1. 路由状态保持（BUG-001）

**问题**: 在任意子页面（如 #sentiment）刷新浏览器后，URL 自动跳回 #dashboard，路由状态丢失。

**根因**: `Router.init()` 方法直接调用 `this.navigate('dashboard')`，没有先读取 `window.location.hash`。

**修复**: 在 `Router.init()` 中先读取当前 hash，验证是否为有效路由，有效则导航到对应页面，无效则默认 dashboard。

**影响范围**: 所有页面刷新行为。

**验证**: 5个测试页面（首页/微博数据/舆情分析/热点趋势/AI日报）刷新后路由状态全部正确保持。

---

### 2. 动态页面标题（BUG-005）

**问题**: 所有页面的浏览器标签页标题都是"微博智能分析平台"，没有区分当前页面。

**修复**: 在 `Router.navigate()` 方法中，根据当前路由的 `PAGE_INFO` 配置动态更新 `document.title`。首页保持默认标题，子页面格式为"{页面名} - 微博智能分析平台"。

**影响范围**: 浏览器标签页标题显示。

**验证**: 5个测试页面标题正确显示，多标签页使用时可清晰区分。

---

### 3. 真实用户名展示（BUG-006）

**问题**: 微博列表中所有用户名显示为"用户1"、"用户2"..."用户10"，详情弹窗作者显示为"未知用户"。

**根因**: 后端 API 返回的用户名字段为 `username`（如 "Dear-迪丽热巴"），但前端代码只检查 `item.user`、`item.author`、`item.screen_name` 三个字段，没有检查 `item.username`，导致 fallback 到"用户X"或"未知用户"。

**修复**: 在两处用户名获取逻辑中，添加 `item.username` 作为第一优先级检查字段。

**影响范围**: 微博数据页面表格和详情弹窗。

**验证**: 用户名正确显示后端返回的真实用户名（如 "Dear-迪丽热巴"），详情弹窗作者正确显示，数据真实有效。
